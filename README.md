## 🌸 Florista - Flower Shop Website

Welcome to **Florista🌸**, a beautifully designed flower shop website built using **Django** and modern web technologies.  
This project showcases a simple yet elegant online platform for browsing and exploring flowers.


## 🌼 About the Project

**Florista** is a Django-based web application that simulates an online flower store.  
It focuses on clean UI design, smooth navigation, and a pleasant user experience.

This project was created as part of learning and internship practice to strengthen full-stack development skills.

---

## ✨ Features

- 🌷 Beautiful and responsive UI
- 🌸 Home page with featured flowers
- 🛍️ Product listing layout
- 📄 Django backend integration
- 🎨 HTML, CSS based frontend design
- 📱 Mobile-friendly layout

---

## 🛠️ Tech Stack

- **Backend:** Django (Python)
- **Frontend:** HTML5, CSS3
- **Database:** SQLite (default Django DB)
- **Other:** Django Templates
